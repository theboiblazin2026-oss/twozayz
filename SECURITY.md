# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest (main branch) | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within TWOZAYZ web properties, please report it privately:

- **Email**: `Twozayz@gmail.com`
- Please include steps to reproduce the issue and details regarding the potential impact.
- All valid security reports will be acknowledged and reviewed promptly.
